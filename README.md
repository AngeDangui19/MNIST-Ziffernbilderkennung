# MNIST-Ziffernbilderkennung

 SchwerpunktLogistische Regression: Untersuchung des Einflusses von Datenaugmentierung, Hyperparameter
Optimierung (GridSearchCV) und Dimensionsreduktion (PCA) auf die Klassifikationsleistung.
• Test-Accuracy 92,64% mit dem Basismodell; Lernkurvenanalyse und Gewichtsvisualisierung zur Mod
ellinterpretation.
• Einordnung der Ergebnisse im Vergleich zu CNN-Referenzwerten (≈98–99%) aus der Vorlesung.
